# Школьный Telegram-бот

Бот для маленькой компании (по умолчанию 3 человека): каждое утро отмечаемся, после школы проверяем обещания и смотрим общую статистику.

## Что уже работает

- ежедневная утренняя карточка с кнопками;
- статусы «приду», «опоздаю», «скорее всего не приду», «не приду»;
- для опоздания — выбор 5–60 минут, время прихода рассчитывается автоматически;
- публичные оценки «пиздабол / не пиздабол» с именами проголосовавших;
- общая статистика прогулов, опозданий и честности;
- история за последние 7 дней;
- первые 3 участника регистрируются сами — никаких Telegram ID в коде или настройках;
- данные хранятся в PostgreSQL и не пропадают после перезапуска Railway;
- работает через long polling, поэтому домен и webhook не нужны.

## Самый простой запуск на Railway с телефона

### 1. Создать бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot` и пройдите два коротких шага.
3. Скопируйте выданный токен. Никому его не отправляйте и не добавляйте в GitHub.

### 2. Развернуть проект

1. Откройте [New Project в Railway](https://railway.com/new).
2. Выберите **Deploy from GitHub repo** → `ArthurdDaun/Telegrambot`.
3. На схеме проекта нажмите **+ New** → **Database** → **PostgreSQL**.
4. Откройте сервис с ботом → **Variables** и добавьте:

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | токен от BotFather |
| `DATABASE_URL` | **Add Reference Variable** → Postgres → `DATABASE_URL` |
| `APP_TIMEZONE` | `Europe/Moscow` (или ваш часовой пояс) |
| `MAX_MEMBERS` | `3` |
| `MORNING_TIME` | `07:00` |
| `SCHOOL_START_TIME` | `08:30` |

Обязательны только `BOT_TOKEN` и `DATABASE_URL`; для остальных уже заданы значения из таблицы. После добавления переменных Railway обычно запускает новый deploy автоматически. Если не запустил — нажмите **Deploy**.

В логах успешный запуск начинается строкой `Starting school attendance bot`. Для polling-бота публичный домен создавать не требуется. Оставьте **одну реплику** сервиса, иначе несколько процессов будут одновременно получать одни и те же Telegram-обновления.

### 3. Включить в Telegram-группе

1. Добавьте бота в вашу общую группу.
2. Админ группы отправляет `/setup 07:00 08:30`, где первое время — утренняя карточка, второе — начало школы.
3. Два остальных участника отправляют `/join`. Админ, запустивший `/setup`, регистрируется автоматически.
4. Отправьте `/today`, чтобы сразу проверить кнопки.

Если место случайно занял не тот человек, админ отвечает командой `/remove` на любое его сообщение. История при этом не удаляется.

## Команды

| Команда | Действие |
|---|---|
| `/today` | отметить статус и увидеть всех за сегодня |
| `/verify` | поставить или изменить оценку обещанию |
| `/stats` | статистика всех участников |
| `/history` | отметки за последние 7 дней |
| `/members` | участники и свободные места |
| `/join` | занять место |
| `/remove` | освободить место; админ отвечает командой на сообщение человека |
| `/settings` | посмотреть время и часовой пояс |
| `/setup 07:00 08:30` | первичная настройка или изменение времени |
| `/help` | справка внутри Telegram |

Конкретные пользовательские ID нигде не задаются. Telegram ID сохраняется только как внутренний технический ключ после добровольного `/join`: это не даёт одинаковым именам и смене username испортить статистику.

## Локальный запуск (необязательно)

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export BOT_TOKEN="токен"
python -m school_bot
```

Без `DATABASE_URL` бот использует локальный файл SQLite `school_bot.db`. На Railway обязательно подключите PostgreSQL.

## Разработка

```bash
pip install -r requirements-dev.txt
pytest -q
```

Схема базы создаётся автоматически при старте. Секретов в репозитории нет.
