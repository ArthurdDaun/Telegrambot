# Школьный Telegram-бот

Приватный бот для компании из трёх человек. Общая Telegram-группа не нужна: каждый пишет боту в личные сообщения, а статусы, проверки и статистика синхронизируются между тремя отдельными диалогами.

## Как это выглядит

1. Первый человек открывает бота и нажимает **«Создать компанию»**.
2. Бот выдаёт короткий код и персональную ссылку-приглашение.
3. Два друга открывают ссылку и автоматически входят в ту же компанию.
4. Каждое утро бот пишет каждому лично и предлагает выбрать статус.
5. Когда кто-то отмечается или ставит оценку, двое остальных получают личное уведомление.
6. `/today`, `/verify`, `/stats` и `/history` показывают общие данные компании.

Никаких Telegram-групп и заранее прописанных пользовательских ID.

## Возможности

- «Я приду в школу»;
- «Я опоздаю» с выбором 5–60 минут и расчётом времени прибытия;
- «Скорее всего не приду»;
- «Я не приду»;
- оценки «пиздабол / не пиздабол»;
- имена проголосовавших видны всем участникам;
- общая статистика прогулов, опозданий и честности;
- история за последние 7 дней;
- ежедневная рассылка по времени Уфы;
- SQLite без PostgreSQL.

## Railway с телефона

### 1. Создать Telegram-бота

1. Откройте [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot` и следуйте подсказкам.
3. Сохраните токен. Не публикуйте его и не добавляйте в GitHub.

### 2. Развернуть

1. Откройте [Railway](https://railway.com/new).
2. Выберите **Deploy from GitHub repo** → `ArthurdDaun/Telegrambot`.
3. В Variables сервиса добавьте:

```text
BOT_TOKEN=новый_токен_от_BotFather
APP_TIMEZONE=Asia/Yekaterinburg
MAX_MEMBERS=3
MORNING_TIME=07:00
SCHOOL_START_TIME=08:30
```

Для первого запуска этого достаточно. SQLite будет создана автоматически внутри сервиса.

### 3. Постоянная статистика

Без Railway Volume бот работает, но SQLite-файл может исчезнуть при новом deploy или перезапуске контейнера. Для постоянного хранения нужен Volume:

1. Откройте Railway с компьютера либо включите в браузере телефона **«Версия для ПК»**.
2. На Project Canvas выберите **Create → Volume**.
3. Подключите Volume к сервису `worker`.
4. Mount Path: `/data`.
5. Добавьте переменную `DATABASE_PATH=/data/school_bot.db` и выполните Redeploy.

Railway предупреждает, что создание Volume в мобильном интерфейсе может не работать. Сам бот не зависит от Volume для запуска — Volume нужен только для сохранения истории между пересборками.

## Настройка пользователей

1. Первый человек открывает личный чат с ботом и отправляет `/start`.
2. Нажимает **«Создать компанию»**.
3. Пересылает полученную ссылку двум друзьям.
4. Друзья открывают ссылку и нажимают **Start**.

Готово. Каждый остаётся в своём личном чате с ботом.

## Команды

| Команда | Действие |
|---|---|
| `/start` | главное меню или вход по ссылке |
| `/create` | создать компанию |
| `/join КОД` | войти по короткому коду |
| `/today` | отметить статус и увидеть всех |
| `/verify` | оценить обещания |
| `/stats` | общая статистика |
| `/history` | история за 7 дней |
| `/members` | участники и ссылка-приглашение |
| `/invite` | повторно получить ссылку |
| `/settings` | настройки времени |
| `/setup 07:00 08:30` | изменить рассылку и начало школы |

Создатель может убрать участника кнопкой в `/members`. Освободившееся место можно занять по той же ссылке.

## Разработка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
export BOT_TOKEN="токен"
pytest -q
python -m school_bot
```
